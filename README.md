Defragment_sborka — разбор сборки Create Chronicles: Bosses and Beyond

## Что это

Исследовательская инфраструктура для полного прохождения модпака
Create Chronicles: Bosses and Beyond v2.5.3 (Minecraft 1.20.1, Forge
47.3.0). Масштаб: 295 модов, 1827 квестов, 31 глава. Проект ведётся
маленькими шагами, каждый факт и метод — «кирпичик», из которых
собирается всё остальное.

## Цель

Построить полный пошаговый план прохождения (лежит в plan/):
все квесты, все предметы хотя бы по разу, заводы для производства
чего угодно.

## Как ориентироваться (порядок чтения)

1. MAP.md — карта всех директорий и файлов.
2. RULES.md — законы репозитория.
3. INDEX.md — реестр: один файл = одна строка.
4. plan/README.md — с чего начать прохождение.
5. progress/TRACKER.md — текущий статус игрока.

## Верхний уровень

| Путь | Назначение |
| --- | --- |
| plan/ | ГЛАВНЫЙ ПРОДУКТ: пошаговый план прохождения |
| plan/auto/ | чек-листы всех 1827 квестов (генерируются) |
| progress/ | Трекер выполнения (ведёт игрок) |
| analysis/ | Аналитика: порядок глав, боссы, гейтинг, потребности |
| data/ | Машиночитаемые факты: моды, квесты, мета |
| tools/ | Python-инструменты (только stdlib) |

## Словарь

- Сборка — модпак Create Chronicles: Bosses and Beyond.
- Глава — файл квестов FTB Quests; базовая единица прогрессии.
- Волна — квесты одной глубины графа зависимостей (в чек-листах).
- Гейтинг — механика постепенного открытия контента (предметы-«машины»).
- Кирпичик — минимальный метод или факт; всё сложное собирается из них.
- JSONL — текстовый формат: одна строка = одна запись.
