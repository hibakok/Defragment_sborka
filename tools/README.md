Инструменты
Python 3, только стандартная библиотека. Запуск из папки tools/:

cd toolspython -m snbt.parser          # проверка парсера на файле-примереpython -m quests.stats         # (будущее) статистика квестов
Ветки кода
core/files.py, core/jsonio.py   — примитивы (кирпичики низшего уровня)snbt/parser.py                  — парсер (собран из примитивов)quests/*                        — анализ квестов (будущее, поверх data/)pipeline/*                      — клей-скрипты (будущее)
Каждый метод задокументирован в METHODS.md: вход / выход / функция.Новый метод = сначала запись в METHODS.md, потом код.
