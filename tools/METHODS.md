окументация методов
Формат записи: метод | файл | вход | выход | функция.Ветка кода читается снизу вверх: каждый метод использует только методыиз своего файла или уровнем ниже.

tools/core/files.py — примитивы файлов
Метод	Вход	Выход	Функция
read_text	путь (str)	текст (str)	Прочитать текстовый файл целиком
write_text	путь, текст	путь	Записать текст в файл (перезапись)
ensure_dir	путь	путь	Создать директорию, если нет
list_files	папка, суффикс	список имён	Файлы папки с данным суффиксом
tools/core/jsonio.py — примитивы JSON
Метод	Вход	Выход	Функция
load_json	путь	объект Python	Прочитать JSON
save_json	путь, объект	путь	Записать JSON (indent=1, юникод)
load_jsonl	путь	список объектов	Прочитать JSONL (1 строка = 1 объект)
save_jsonl	путь, список	путь	Записать JSONL (1 объект = 1 строка)
tools/snbt/parser.py — парсер SNBT
Метод	Вход	Выход	Функция
parse_snbt	текст SNBT (str)	dict/list/str/число	Главный вход парсера
_strip_comments	текст	текст	Убрать комментарии //
_peek	—	символ	Текущий символ ('' = конец)
_error	сообщение	raise	Ошибка с контекстом
_skip_ws	—	—	Пропустить пробелы/переводы строк
_value	—	значение	Выбор: объект/массив/строка/число/слово
_object	—	dict	Разбор { ключ: значение } (запятые опциональны)
_array	—	list	Разбор [ ... ] (запятые опциональны)
_typed_array	—	list	Разбор [I; 1 2 3] (типизированный NBT-массив)
_string	—	str	Разбор "..." с экранированием
_number	—	int/float	Разбор 1, 2.5d, 100L (суффиксы типов NBT)
_word	—	True/False/str	Разбор true/false/голого слова
_key	—	str	Разбор ключа объекта
Поддерживаемый диалект: SNBT файлов FTB Quests — запятые междуэлементами могут отсутствовать (разделитель — перевод строки).
