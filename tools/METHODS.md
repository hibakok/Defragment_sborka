# Документация методов

Формат записи: метод | вход | выход | функция.
Ветка кода читается снизу вверх: каждый метод использует только методы
из своего файла или уровнем ниже. Порядок ветки:
core → snbt/quests (доменные) → plan (отрисовка) → pipeline/extract (склейки).
