# Этап 17: фабрики — «завод на каждый предмет»

## Цель

Построить производственную систему, выпускающую ЛЮБОЙ предмет
сборки в «астрономических» количествах. Ответ на требование
«один завод на предмет» состоит из ДВУХ слоёв:

1. **Универсальный завод = МЭ-автокрафт (этап 11).** Для любого
   предмета, у которого есть крафт-рецепт (а их ~26 500 в
   items.jsonl, рецепты — data/recipes/*.jsonl + JEI), МЭ-сеть с
   молекулярными сборщиками (molecular assembler) собирает его ПО ЗАКАЗУ в любом
   количестве. Один «зал автокрафта» = заводы всех предметов.
2. **Bulk-фабрики Create** для массовой БАЗЫ: сырьё, механизмы,
   еда, стройматериалы — то, что нужно тысячами (demand.jsonl).

Ниже — каталог фабрик. Приоритет = номеру блока.

## Блок 0 — инструменты репозитория (проверено данными)

- `python -m recipes.tree <modid:item>` (из tools/) — полное дерево
  «что нужно для предмета с нуля», по слоям, с машинами
  (данные: data/recipes + data/kubejs, 10 682 рецепта).
- data/production.jsonl — для каждого из 22 501 предметов: маркер
  (к — крафт, 5 901 шт.; в — ваниль; н — лут/дроп) и список машин.
- analysis/production_map.md — покрытие крафта по модам: где
  автокрафт закрывает всё, где нужны лут-маршруты.

## Блок А — лестница механизмов (7 SA-линий)

Каждая линия: депо-конвейер + деплоеры (по шагам SA) + пресс.
Вход — выход линии уровнем ниже (analysis/gating_items.md).

| Линия | Выпуск/час (4 депо, 256 об/мин) | Комментарий |
| --- | --- | --- |
| L1 rotation (плита+сплав+молот) | ~700 | молот НЕ расходуется |
| L2 hydraulic (медь+стекло+ключ) | ~350 | ключ не расходуется |
| L3 precision (латунь+лампа+шестерня) | ~170 | лампа: деплой-линия |
| L4 locomotive (лист+слизь+арматура×2) | ~170 | арматура: резка скрапа |
| L5 steel (TFMG: плита+сталь+Al+винт×2) | ~170 | винты с пресса |
| L6 infernal (бензин+магма+ember) | ~170 | нужен жидк. дозатор |
| L7 calculation (radiance+олово+катушка+оптика) | ~170 | радианс: Луна! |

Квоты (demand.jsonl): sealed 3001, vibration 3001, calculation
2049, precision 1026, hydraulic 1026, locomotive 1026, steel
1025, rotation 514, engineering_processor 257. Линии L1–L2 —
двумя экземплярами (об/мин×2), L3+ — по одной, но 24/7.

## Блок Б — сырьевые мега-фермы

1. Дерево: 2× фермы пил (дуб+тёмный дуб), ~стак/мин.
2. Андезит: генератор булыжника→? нет: шахта+данж-туф; лучше —
   «жерло» 15c (asurine-жерло) и дробление.

6. Порох: земля→нитрат→порох (этап 10, блок А).
7. Certus: бутон-ферма (main.js:309–338).
8. Радианс: лунные деревни (loot.js:386) — маршрутный бот.
9. Золото (яблоки ×2000!): свинозолото/жерла+пустынные храмы?
   + автокрафт яблок в МЭ.
10. Еда (рынок ×5000): фермы пшеницы/капусты/ягод/молока/какао;

## Блок В — «астрономический» объём: цифры

Полное прохождение требует (demand.jsonl): ~40 000 предметов
суммарно; «астрономический задел» = ×100 к квоте: миллионы.
Достижимо только слоями: (1) МЭ-склад 64k-ячейки ×10; (2) линии
А работают 24/7 (чанки загружены — см. Блок Д); (3) «выходной
день»: заказ 10 000 шт любого предмета через автокрафт — и уйти
играть дальше, МЭ соберёт сама.

## Блок Д — производительность (FX-4100 + GT 1030)

ЖЕЛЕЗО СЛАБОЕ: 4 ядра 2011 года, GPU 2 ГБ. Правила:

1. RAM и Java-флаги: строго по plan/00_setup.md (шаг 3) — не
   изобретай свои: там проверенный набор G1GC.
2. Моды уже включают ModernFix/radium — не добавляй дубликаты.
3. Видеонастройки: рендер 6–8 чанков, частицы «минимум»,
   шейдеры ВЫКЛ (в сборке есть встроенные — выключи!), VBO on.
4. Фабрики — компактно: 1 чанк = 1 линия; «спящие» линии
   (redstone-стоп при полном буфере) — иначе тик-лаг.
5. Не ставь 20 000 предметов на конвейер лёжа: entity-лаг.
   Используй поезда/депо-склады, предметы в контейнерах.
6. Автосейв 30 мин;_world backup раз в сеанс (см. 00_setup.md).
7. Загрузка чанков: форлоты?? — только ванильный спавн-чанки +
   поезда по маршрутам (форс-лоадер create_power_loader есть в
   сборке — используй его для «ядра» фабрик, 1 чанк).
