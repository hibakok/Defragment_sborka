## Блок А — взрывная цепочка (волны 1–3, 27+8+3 квеста)

1. minecraft:dirt ×1, charcoal — триггеры. ГЛАВНОЕ: земля
   ДРОБИТСЯ → tfmg:nitrate_dust (шанс 20%, data/recipes/tfmg/
   crushing/saltpeter.json). Ферма земли: бур + булыжник→…? нет:
   простоEXCAVATOR Create (котлован) или биг-дробилка земли.
2. minecraft:gunpowder: смешивание 3× nitrate_dust + 2× charcoal +
   tfmg:sulfur_dust → 6× пороха (tfmg/mixing/gun_powder.json).
   Сера — из TFMG-руд (sulfur). Альтернатива: тухловая мука +
   25mB вредного зелья (create/filling/gunpowder.json).
3. ae2:tiny_tnt — крафт из пороха+кварца (JEI).
4. minecraft:oak_wood — «стволы»: ферма деревьев (мех. пилы).
5. Итог блока: линия ДЕРЕВО+ЗЕМЛЯ+СЕРА → ПОРОХ на 6× за микс.

## Блок Б — сингулярности AE2 (волны 4–7)

1. ae2:ender_dust — пыль Эндера: ПЕЧАТАТОР AE2 (inscriber),
   жемчуг в середину (data/recipes/ae2/…/ender_dust.json).
2. ae2:matter_ball — шары материи: конденсатор AE2 / JEI
   (в данных рецептов прямого крафта нет — проверь R).
3. ae2:singularity — сингулярность (JEI: из пыли Эндера;
   в data/recipes/ae2 нет — крафт через конденсатор?).

   пыль) ПОД ВЗРЫВОМ → 2 пары (ae2:transform, explosion —
   data/recipes/ae2/…/entangled_singularity*.json).
4. ae2:tiny_tnt = 2× кварцевая пыль + 2× ПОРОХ (шахматный
   крафт, ae2/…/tiny_tnt.json) — и есть «взрыватель» пар:
   пороховая линия из Блока А питает. ЛУЧШИЙ расходник —
   tiny_tnt: маленький взрыв не портит окрестности.

## Блок В — хроматическая цепочка (волны 8–9, по 16 квестов)

1. create_dd:spectral_ruby = аметист + 7× светопыль (shapeless).
   Аметист: ферма аметистовых бутонов (друза+лом+обсидиан).
   Светопыль: ведьмы (HNN!) или лут.
2. polished_spectral_ruby: полировка наждаком (SA-деплой) или
   superheating-скороварка create_dd.
3. create_dd:chromatic_compound: смешивание 4× ОБСИДИАНОВАЯ ПЫЛЬ +
   полир. розовый кварц + полир. спектральный рубин → 2×
   (superheated). Пыль обсидиана — дробление обсидиана (этап 05).
   Альтернатива: полир. рубин + matter_ball + 500mB хроматического
   стока → 2× (main.js:1008). Сток хроматики: опустошение лишней
   хроматики (main.js:1010, emptying → 250mB + compound_base).
4. create_dd:refined_radiance — сияние: ЛУННЫЕ сундуки (основной
   источник, loot.js:386–403) — планерные рейды на Луну за
   радиансом; ЛИСТ сияния — прессование слитка.

## Блок Г — расчётный механизм (волны 10–20)

1. create_optical:optical_device — оптический прибор (Create
   Optical, JEI: линзы+...). Мелочь, но без него SA не собрать.
2. create_dd:calculation_mechanism: SA от infernal_mechanism,
   2 петли: лист сияния → оловянный лист → медная катушка →
   оптический прибор → пресс (main.js:1015). Побочно 5%: катушка,
   хроматика, электронная лампа.
3. create_dd:integrated_circuit: SA от расчётного механизма:
   лист перегруз. сплава → control_chip → светопыль → резистор →

   32 ПЕТЛИ (!): латунный+электрум самородки (main.js:1046) —
   это «медленный» крафт: поставь отдельную линию заранее.
4. Overcharge alloy: заряжание хроматики 10M FE на станции
   createaddition (recipes/create_dd/…/overcharge_alloy.json) —
   тесла-катушка/зарядник. Лист — прессование. (Для интегр. схем.)
