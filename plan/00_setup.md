# Этап 00: установка и оптимизация

## Цель

Сборка установлена, запускается, FPS играбельный на FX-4100 + GT 1030.
Мир создан, бэкапы настроены.

## Предусловия

Нет. Это первый этап.

## Честные ожидания

295 модов на 4-поточном CPU 2011 года: загрузка мира 2–5 минут,
FPS 15–40 в зависимости от биома и построек. Это норма для этого железа.
В сборке уже есть оптимизаторы: ModernFix, Embeddium, FerriteCore,
Alternate Current, AI Improvements, Better FPS Render Distance.
Шейдеры в сборке ВЫКЛЮЧЕНЫ по умолчанию — НЕ включай их: GT 1030 2 ГБ
рассчитана на ванильную картинку.

## Шаги

### Шаг 1. Лаунчер (выбери один)

Вариант А (рекомендую для слабого ПК): Prism Launcher.

1. Скачай с prismlauncher.org, установи.
2. Java: установи Temurin 17 (adoptium.net, версия JRE 17, Windows x64).
   Prism может скачать сам: Настройки → Java → Автоматически.

Вариант Б: CurseForge App (официальный, но тяжелее на слабом ПК).

1. Скачай с curseforge.com, установи, войди.

### Шаг 2. Установка сборки

1. Prism: Добавить инстанс → CurseForge → поиск «Create Chronicles
   Bosses and Beyond» → выбрать версию 2.5.3 → Установить.
2. CurseForge App: Minecraft → Browse Modpacks → тот же поиск → Install.
3. Папка инстанса: запомни путь (в Prism: правый клик → Папка).

### Шаг 3. Память и Java

Правый клик по инстансу → Настройки → Java:

- Если в ПК 16 ГБ ОЗУ: `-Xms8G -Xmx8G`
- Если 8 ГБ ОЗУ: `-Xms5G -Xmx5G` (закрой браузер и лишние программы!)

Флаги JVM (вставить целиком после -Xmx):

```
-XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200
-XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC
-XX:G1NewSizePercent=30 -XX:G1MaxNewSizePercent=40
-XX:G1HeapRegionSize=8M -XX:G1ReservePercent=20
-XX:G1HeapWastePercent=5 -XX:G1MixedGCCountTarget=4
-XX:InitiatingHeapOccupancyPercent=15
-XX:G1MixedGCLiveThresholdPercent=90
-XX:G1RSetUpdatingPauseTimePercent=5 -XX:SurvivorRatio=32
-XX:+PerfDisableSharedMem -XX:MaxTenuringThreshold=1
```

Java: Temurin 17.

### Шаг 4. Первый запуск

1. Запусти инстанс. Первый запуск — 3–10 минут (ModernFix собирает
   кэш). Не паникуй, если долго висит «загрузка».
2. Дальнейшие запуски быстрее (1–3 минуты).
3. Если краш с OutOfMemory: уменьши -Xmx на 1 ГБ и закрой лишние
   программы.

### Шаг 5. Настройки видео (главное меню → Настройки → Видео)

| Параметр | Значение |
| --- | --- |
| Дальность прорисовки | 7 (5 если лагает) |
| Дальность симуляции | 5 |
| Графика | Быстрая |
| Плавное освещение | Выкл |
| Частицы | Минимум |
| Тени сущностей | Выкл |
| Дальность сущностей | 75% |
| Смешивание биомов | 1 |
| Mipmap | 1 |
| Облака | Выкл |
| Виньетка (Embeddium) | Выкл |
| Полный экран | Вкл |
| V-Sync | Вкл |

### Шаг 6. Создание мира

1. Один игрок → Создать новый мир.
2. Режим: Выживание. Сложность: Обычная. Читы: Вкл (страховка).
3. Сид: любой (запиши его в TRACKER).
4. Задатки мира: дефолтные от сборки (Terralith уже включён).
5. Создание мира занимает 2–5 минут — это нормально (тяжёлый worldgen).

### Шаг 7. Бэкапы (важно!)

1. Путь мира: `<папка инстанса>/saves/<имя мира>`.
2. После КАЖДОГО сеанса: закрой игру, скопируй папку мира в
   `WorldBackup_ГГГГ-ММ-ДД` (храни 3 последних).
3. Прогресс квестов хранится ВНУТРИ папки мира — бэкап мира = бэкап
   квестов.

## Критерий готовности

- [ ] Сборка 2.5.3 запускается без крашей
- [ ] FPS в мире ≥ 15 (проверка: F3, строка FPS)
- [ ] Мир создан, сид записан
- [ ] Первый бэкап сделан
