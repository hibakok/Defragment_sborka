## Блок А — certus-конвейер (волны 1–5)

1. Бутон-ферма: смешивание вода 100mB + песок + сахар ×2 + кварц →
   малый бутон (main.js:309). Рост: SA с заливкой воды ×3 петли на
   тир (малый→средний→большой→кластер, main.js:311–336). Кластер →
   фрезеровка → 3 кристалла (main.js:338). ЗАМКНУТЫЙ ЦИКЛ: часть
   кристаллов → заряжатель → charged_certus; часть — снова в рост.
2. Заряжатель (charger): FE от alternator; кристалл → заряженный.
3. Наждачная бумага/печи не нужны: всё через деплои и пресс.

## Блок Б — процессоры (волны 6–7)

1. Пресс-формы (4 шт): Лунные подземелья (loot.js:410) ИЛИ крафт
   (алмазы+...). silicon/logic/calculation/engineering.
2. Печатные платы: SA createappliedkinetics — например printed_
   calculation_processor: SA от integrated_circuit: деплой заряж.
   кварца → деплой ПРЕСС-ФОРМЫ (не расходуется) → пресс
   (main.js:1060). Аналогично printed_silicon/logic/engineering.
3. Процессоры: сборка на прессе (кремний+золото/железо+...:
   JEI). engineering_processor = печатная инж. плата + кремний +
   алмаз (JEI). 257 штук — это ОГРОМНЫЙ попутный спрос (чёрный
   рынок): держи СА-линии процессоров работающими.

## Блок В — МЭ-сеть (волны 8–9, 8+15 квестов)

1. ae2:controller — контроллер: 8× инженерных процессоров (JEI).
   Питание: FE (alternator+аккумулятор). Вставь мини-сетку:
   controller + drive + terminal.
2. ae2:drive + storage_cell (4k/16k/...): носители = кремний+
   процессоры. Начни с 4k, апгрейдь до 64k по ходу.
3. ae2:terminal — доступ. p2p-туннели, io-порт, crafter-мейнбрейн.
4. Интерфейсы: fluid/interface; ctor-шина для подачи в Create.

## Блок Г — автокрафт (волны 10–11)

1. molecular_assembler — молекулярные сборщики: скорость ×шт.
   Поставь батарею 8–16 сборщиков в «зал автокрафта».
2. pattern_provider + паттерны: запиши рецепты (шаблоны) на всё,
   что крафтишь регулярно (сплавы, листы, механизмы...).
3. ae2:quantum_ring + quantum_link + entangled_singularity —
   квантовый мост (мультичанк-сеть). 16 колец — попутный квест.
4. Автокрафт = ЗАВОД НА КАЖДЫЙ ПРЕДМЕТ (см. план 17): любой
   предмет с рецептом → заказ через терминал → МЭ собирает сам.
