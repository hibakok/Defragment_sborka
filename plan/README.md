# План прохождения

## Трёхслойная структура плана

1. **plan/auto/NN_глава.md — чек-листы квестов (генерируются из данных).**
   Все 1827 квестов, отсортированы топологически (зависимости всегда
   выше), сгруппированы в волны. Отмечай выполнение прямо в них:
   `- [ ]` → `- [x]`. Перегенерация (`python -m pipeline.skeleton_all`
   из tools/) СОХРАНЯЕТ галочки — можно спокойно обновлять.
2. **plan/museum/<мод>.md — чек-листы предметов (цель «все хотя бы
   по разу», 22 501 шт., генерируются).** Маркер в строке: · к —
   рецепт есть (фабрика/автокрафт), · в — ваниль (JEI), · н — лут/
   дроп/данж. Перегенерация (`python -m pipeline.museum_all`) тоже
   сохраняет галочки; прогресс — `python -m pipeline.museum_count`.
3. **plan/NN_название.md — стратегия (писалась ИИ по главам).**
   Цель / Предусловия / Шаги-блоки (сеанс ≈ блок) / Критерий готовности /
   Что дальше. Номер = этап (совпадает с TRACKER.md).

## Соглашения

- Выживание, сложность Normal, читы только для бэкапов.
- Перед каждым сеансом: `python -m pipeline.progress_count` (квесты) и
  `python -m pipeline.museum_count` (предметы) из tools/ — сводки
  прогресса для TRACKER.md.
- Рецепты: точные данные уже в репозитории: data/recipes/*.jsonl
  (моды), data/kubejs/server_scripts/main.js (кастомные), summary —
  analysis/gating_items.md. Дерево «что нужно для предмета с нуля»:
  `python -m recipes.tree <modid:item>` из tools/. В игре сверяй через
  JEI (R по предмету).
