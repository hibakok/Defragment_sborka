# План прохождения

## Двухслойная структура плана

1. **plan/auto/NN_глава.md — чек-листы (генерируются из данных).**
   Все 1827 квестов, отсортированы топологически (зависимости всегда
   выше), сгруппированы в волны. Отмечай выполнение прямо в них:
   `- [ ]` → `- [x]`. Перегенерация (`python -m pipeline.skeleton_all`
   из tools/) СОХРАНЯЕТ галочки — можно спокойно обновлять.
2. **plan/NN_название.md — стратегия (пишется ИИ по главам).**
   Цель / Предусловия / Шаги-блоки (сеанс ≈ блок) / Критерий готовности /
   Что дальше. Номер = этап (совпадает с TRACKER.md).

## Соглашения

- Выживание, сложность Normal, читы только для бэкапов.
- Перед каждым сеансом: `python -m pipeline.progress_count` (из tools/)
  — сводка прогресса для TRACKER.md.
- Рецепты кастомных предметов сборки смотри в JEI (R по предмету);
  точные данные появятся в data/kubejs/ после экстракции инстанса.
