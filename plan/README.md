План прохождения
Как читать
Файлы плана нумеруются в порядке прохождения: 00_, 01_, 02_...Каждый файл = один этап. Структура каждого файла:

Цель — что даёт этап.
Предусловия — что должно быть готово до начала.
Шаги — нумерованные конкретные действия (один шаг = одно действие).
Критерий готовности — как понять, что этап закрыт.
Что дальше — переход к следующему этапу.
Статус файлов плана
Файл	Этап	Статус
00_setup.md	Установка и оптимизация	готов
01_basics.md	Начало: первые квесты	в работе
(далее — по карте глав analysis/progression_map.md)		
Соглашения
Играем на выживании, сложность Normal, читы разрешены (только длястраховки и бэкапов — не для читерства).
Каждый игровой сеанс начинается с проверки TRACKER.md.
Прогресс отмечается в progress/TRACKER.md после каждого сеанса.
