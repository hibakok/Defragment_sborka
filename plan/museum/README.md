# Музей предметов

Цель «все предметы сборки хотя бы по одному экземпляру» — 22 501
предмет, чек-листы по модам (136 файлов + этот README).

## Как пользоваться

1. Один файл = один мод (большие моды делятся на части: `_part2` и т.д.).
2. Предмет попал в музей (МЭ-сеть / сундук-витрину) — отметь строку:
   `- [ ]` → `- [x]`. Больше НИЧЕГО в файлах не менять (RULES.md).
3. Прогресс: `cd tools && python -m pipeline.museum_count` — таблица
   по модам и итог для progress/TRACKER.md.
4. Перегенерация (`python -m pipeline.museum_all`) СОХРАНЯЕТ галочки.

## Маркеры в строках

- `· к` — рецепт есть в данных (data/recipes + data/kubejs):
  фабрика/МЭ-автокрафт возможны. Всего 5 901 предмет.
- `· в` — ванильный minecraft: рецепт в клиенте игры, смотри JEI.
- `· н` — рецепта в данных нет: лут, дроп мобов, данжи, торговля
  или мод вне выборки извлечения. «н» ≠ «некрафтимо» — сначала
  проверь в JEI (клавиша R), потом ищи источник добычи.

## Подробности

- Карта покрытия по модам: analysis/production_map.md.
- Точные данные каждого предмета: data/production.jsonl
  (маркер, число способов, машины).
- Дерево «что нужно для предмета с нуля»:
  `python -m recipes.tree <modid:item>` из tools/.
- Источник имён: data/items.jsonl (26 500 lang-строк → фильтр
  tools/items/ids.py → 22 501 чистых предметов).
