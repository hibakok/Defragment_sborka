# Этап 12: космос — Венера, Марс, Гласио

## Цель

Закрыть три главы: space_ii_to_venus (11), space_iii_to_mars (10),
space_iii_to_glacio (11). Построить ракеты 2–4 тира, собрать
mithril/sol_ingot, острум, калорит, драконью кузницу молний.

## Предусловия

- Этап 09: лунная база, де́ш; этап 11: МЭ-сеть (возить хабар домой).
- Чек-листы: plan/auto/12a/b/c_*.md.
- Тир ракет: 2 = де́ш (Луна), 3 = острум (Марс), 4 = калорит (Венера).

## Блок В — Гласио (12c: to_glacio, 11 квестов)

Порядок этапов (tools/plan/route.py): 12a=Марс → 12b=Венера →
12c=Гласио. Тиры ракет растут по порядку: 2 → 3 → 4.

1. tier_4_rocket (калорит) → Гласио: лёд/кристаллы.
2. iceandfire: кузница молний (lightning dragonforge):
   dragonforge_lightning_brick ×17 (/input/core_disabled) —
   кузница собирается из кирпичей (рецепты Ice and Fire),
   кормится дыханием молниевого дракона →
   dragonsteel_lightning_ingot (топ-материал).
3. lightning_dragon_blood — кровь молниевого дракона: убей
   (iceandfire:lightning_dragon, гл. 15a — совместимый квест).
4. jet_suit (реактивный костюм Ad Astra) — полёты без ракет.
